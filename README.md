# 코코포리아 로그 리더

[ココフォリア(CCFOLIA)](https://ccfolia.com/)에서 내보낸 로그 HTML 파일을 읽기 편한 형태로 바꿔 주는 웹 도구입니다.

## 사용 방법

1. 페이지를 열고 코코포리아 로그 HTML 파일을 화면에 끌어다 놓거나 **파일 열기**로 선택합니다.
2. 필요한 옵션을 조절합니다.
3. **HTML 저장**으로 결과를 내려받거나, **텍스트 복사**로 일반 텍스트를 복사합니다.

## 기능

- 같은 캐릭터의 연속 대사는 이름을 한 번만 표시하고, 캐릭터별 이름 색을 유지합니다.
- 맨 위에 시나리오 제목을 입력할 수 있습니다. 파일 이름으로 자동 입력됩니다.
- 글자 크기와 폭을 슬라이더 또는 숫자 입력으로 조절하고, 폭을 화면에 맞출 수도 있습니다.
- 로그에 포함할 탭을 선택할 수 있습니다. 탭 목록은 메인 / 정보 / 잡담 / 그 외 순서로 나오고, 한국어·영어·일본어 탭 이름(main·메인·メイン, info·정보·情報, other·잡담·雑談)을 모두 인식합니다. 처음에는 메인 탭만 체크됩니다. 체크를 해제한 탭은 화면, 텍스트 복사, 저장되는 HTML에서 모두 빠집니다.
- 잡담 탭 등 선택한 탭의 대사를 화면 폭의 지정한 위치(기본 50%)부터 좌측 정렬로 표시합니다.
- 대사를 클릭해 오타를 바로 고칠 수 있습니다.
- 필요 없는 대사는 삭제할 수 있고, Ctrl+Z / Ctrl+Y로 되돌리기와 다시 실행이 가능합니다.
- 저장되는 HTML은 배경이 투명한 조각 형태라, 블로그 등의 HTML 모드에 붙여 넣어도 페이지 배경이 바뀌지 않습니다.

## 개인정보

모든 처리는 브라우저 안에서만 이루어집니다. 불러온 로그 파일은 서버로 전송되거나 저장되지 않습니다.
